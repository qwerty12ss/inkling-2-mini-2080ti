# Фото для проверки vision

`coffee-code.jpg` — изображение 1024 × 768 из теста GPU-vision 448K. Внизу добавлена белая полоса с кодом. Ожидаемый ответ — **COFFEE Q7M42**. При текущем процессоре Inkling картинка занимает 521 входной токен вместе с маркером изображения. Проверка SHA-256 входит в модульные тесты.

Фото чашки в Pikolo Espresso Bar сделала Rachel Michetti, которая опубликовала его под CC0. Источник — набор scikit-image v0.25.2. Для опыта фото масштабировали и добавили подпись.
